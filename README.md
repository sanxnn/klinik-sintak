# KlinikSintak — Premium Coding Agency & SEO Assassin

🌐 **KlinikSintak** adalah website official company profile untuk agensi jasa pengembangan aplikasi **web, mobile, & optimasi SEO**. Berfokus pada penyediaan solusi instan untuk tugas akhir mahasiswa, MVP startup, hingga web korporat dengan standar *clean code*, *high performance*, dan arsitektur modern.

Website ini dirancang sebagai single-page landing page premium yang ultra-ringan, interaktif, dan menusuk langsung ke target pasar.

---

## ✨ Fitur Utama

- 🎨 **SaaS Premium UI/UX Design**
  - Desain clean, mahal, dan minimalis menggunakan kiblat tech agensi internasional.
  - Menggunakan font **Plus Jakarta Sans** yang tajam dan profesional.
  - **Full Responsive** (Desktop, Tablet, dan Mobile view murni tanpa grid ampas).

- 📁 **Rekam Medis Portofolio (Case Studies)**
  - Showcase project elite yang berhasil disembuhkan (Laravel full-stack, Flutter mobile app, SEO page #1 rank, dan native cURL API-lookup).

- ⚡ **Direct WhatsApp Order Path (Zero Latency)**
  - Gak pake form order ribet/maintenance database. Konversi langsung dilempar via tautan WhatsApp API otomatis dengan draf teks kustom sekali klik.

- ⬆️ **Smooth Utilities**
  - Tombol *Floating Back to Top* otomatis cerdas (muncul via scroll monitor dengan efek *fade-in + slide-up*).
  - Animasi halus *pulsing heart* pada kredit footer tim pengembang.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5 (Murni Native)**
- **Tailwind CSS v4 (Official Browser CDN @4)** $\rightarrow$ Tanpa biner node_modules, tanpa kompilasi Vite, super cepat di-load.
- **Vanilla JavaScript (Murni)** $\rightarrow$ Bebas dari library purba sekelas jQuery.
- **Google Fonts (Plus Jakarta Sans)**
